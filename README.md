## Repository Structure
- `input.xlsx`: Input dataset for loan approval logic.

- `TraditionalProgrammingVsML.ipynb`: Machine learning decision tree model for loan predictions.
- `MLFramework_HuggingFace_SentimentMonitorjalal.ipynb`: Hugging Face sentiment analysis framework across multiple problem domains.
- `MLFramework_RetrievalAugmentedGeneration.ipynb`: Retrieval-Augmented Generation script featuring custom validation and filtering rules.
